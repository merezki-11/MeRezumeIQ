**MeRezumeIQ**



MeRezumeIQ is an AI-powered resume screening tool that uses Natural Language Processing (NLP) and Machine Learning to analyze resumes and predict job-fit categories.  

It helps automate the process of understanding and categorizing resumes, saving time for HR teams and recruiters.





Project Overview



This project trains an ML model on a dataset of resumes. The model learns to identify job categories based on resume text and can predict the category of a new or unseen resume.



It consists of:

\- A Jupyter Notebook (`MeRezumeIQ.ipynb`) for model training and testing.  

\- A Python script (`app.py`) that loads the trained model and provides an interface for predictions.  

\- Saved model files (`model.pkl`, `vectorizer.pkl`).  

\- A dataset (`UpdatedResumeDataSet.csv`) used for training.
